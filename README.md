# GBX SWIGGY PRO 🍔

GBX SWIGGY PRO is an advanced Telegram Mini App designed for restaurant search, live menu browsing, cart management, and real-time pricing powered by Swiggy's backend architecture.

## 🚀 Features
- **Telegram WebApp Integration**: Built with official Telegram SDK and automated request signing.
- **Real Swiggy API Proxy**: Direct backend routing for location geocoding, restaurant discovery, menus, and cart sync.
- **Advanced Customisation**: Supports size variants, crust options, and add-ons with real-time bill calculations.
